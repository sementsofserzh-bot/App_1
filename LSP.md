# Контракт единицы работы

`IUnitOfWork` предоставляет два репозитория, которые участвуют в одной группе
изменений. Вызовы `Add`, `Update` и `Delete` подготавливают изменения. `Save()`
сохраняет всю группу атомарно. Освобождение объекта без `Save()` отменяет
неподтверждённую группу. После `Save()` можно начать следующую группу.
Идентификатор новой записи следует считать постоянным только после `Save()`.

У Dapper оба репозитория используют одно соединение и транзакцию. У EF оба
репозитория используют один `DBContext`. Прямое создание отдельного Dapper-
репозитория сохраняет его прежнее поведение: операция записывается сразу.
